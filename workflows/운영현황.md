## 데이터 흐름 (하이브리드)

```
[사장님 PC 작업 스케줄러]
   ↓ 5분마다
[update_data.py 실행]
   ↓
[7개 API 수집 — 한국 IP 필요한 한강홍수통제소 포함]
   ↓
[data.js + 상황판.html 자동 생성]
   ↓
[git push -A (PAT는 .git/config에 저장됨)]
   ↓
[GitHub Actions가 push 감지 → Pages 배포 (30초)]
   ↓
[동료들은 URL로 항상 최신 데이터 확인]
```

⚠️ **중요:** GitHub Actions 자체에서 데이터 수집하면 한강홍수통제소 API가 차단(IP 차단). 그래서 사장님 PC가 수집·push 담당, Actions는 배포만.

## 완성된 기능 (8개 API 연동)

| API | 출처 | 데이터 |
|---|---|---|
| 단기예보 | 기상청 | 시군별 24시간 시간별 예보 |
| 초단기실황 | 기상청 | 실측 기온·풍속·강수 |
| 기상특보 | 기상청 (WthrWrnInfoService) | 경기북부 발효 특보 |
| 통보문·기상정보 | 기상청 | 특보 전문 + 기상정보 이력 |
| 미세먼지 | 환경공단 에어코리아 | 10개 시군 PM10·PM2.5 |
| 산불 위험도 | 국립산림과학원 forestPointV2 | 권역별 4단계 |
| 산불발생통계 | 산림청 forestStusService | 최근 1년 발생 내역 |
| 하천 수위 | 한강홍수통제소 | 6개 하천 + 군남댐 (24h history) |
| 재난문자 | 행안부 safetydata.go.kr | 경기도 전체 (북부 우선) |

## UI 구성

### 헤더
- 진한 네이비 + 노란 사이렌 로고 박스
- 토글: 광역 / 내관서 중점
- 시군 변경 버튼 (내관서 모드)
- 📡 기상영상 버튼 (기상청 레이더/위성/낙뢰 iframe 모달)
- 🚨 알람 테스트 / 🔊 음소거 / 🌙 테마 토글
- 시계 (큰 노란 글씨)

### KPI 바 6칸
종합상태 / 발효특보 / 재난문자 / 동두천 기온 / 신천 수위 / 군남댐 저수율

### 광역 모드 그리드 (3x3)
```
시군별 기상 (col 1, 3행 전체)  │  발효 특보  │  재난문자
                              │  산불 위험  │  하천 수위
                              │  시간대별 예보 (col 2-3 row 3)
```

### 내관서 중점 모드 (3x3 + 4행 가로 전체)
- 시군 선택 모달 (10개 시군)
- 1행: 현재 기상 / 인근 수위 (여러 하천) / 미세먼지
- 2행: 12시간 예보 / 산불 / 발효 특보
- 3행: 재난문자 / 광역 특보
- 4행: 24시간 시간대별 상세 표 (가로 전체)

### 모달 (6종)
1. 시군 카드 클릭 → 시군 상세 (초단기실황, 누적강수)
2. 하천 클릭 → 24시간 차트 + CCTV(또는 댐 자료 링크)
3. 미세먼지 패널 → 시군별 비교 차트
4. 산불 패널 → 권역별 + 발생 내역 + 4단계 설명
5. 재난문자 항목 → 메시지 전문
6. 발효 특보 패널 → 통보문 + 기상정보 이력

### 알림 시스템
- 펄스: 경보 배너 한 곳만 (나머지는 정적 색 변경)
- 사운드: Web Audio API 자체 비프 (severe=3연속, warning=2연속, 일반=1)
- 음소거 토글 + 🚨 테스트 버튼
- 종합상태 KPI 칸은 글로우 없이 색만

### 디자인 톤
- **라이트 모드 (기본)**: 베이지 본문 + 흰 카드 + 진한 네이비 헤더 + 노란 강조 — 공공기관 PoC 톤
- **다크 모드 (옵션)**: NORAD 톤 (관제실 야간 운영용)

### 시각화
- 시간대별 예보: SVG 라인 차트 (Bloomberg 스타일)
- 하천 수위: 24시간 미니 sparkline (각 항목 안)
- 시군 카드: 좌측 4px 컬러 바 (위험도)
