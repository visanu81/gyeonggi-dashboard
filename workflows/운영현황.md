## 완성된 기능 (10개 API 연동)

| API | 출처 | 데이터 |
|---|---|---|
| 단기예보 | 기상청 | 시군별 24시간 시간별 예보 |
| 초단기실황 | 기상청 | 실측 기온·풍속·강수 |
| **기상특보 (발효 + 예비)** | 기상청 (WthrWrnInfoService getPwnStatus) | 발효(t6) + **예비특보(t7)** 파싱 — 경기북부 매칭 |
| 통보문·기상정보 | 기상청 | 특보 전문 + 기상정보 이력 |
| 미세먼지 | 환경공단 에어코리아 | 10개 시군 PM10·PM2.5 |
| 산불 위험도 | 국립산림과학원 forestPointV2 | 권역별 4단계 |
| 산불발생통계 | 산림청 forestStusService | 최근 1년 발생 내역 |
| 하천 수위 | 한강홍수통제소 (waterlevel/dam) | 7개 하천(신천 동두천·연천, 임진강 필승교·임진교, 한탄강 용담교, 왕숙천, 중랑천) + 군남댐 (24h history) |
| **홍수예보 발령** | **한강홍수통제소 fldfct** | **주의보·경보 발령 정보 (전국 24시간, 경기북부 매칭 강조)** |
| 재난문자 | 행안부 safetydata.go.kr | 경기도 전체 (북부 우선) |

⚙️ **예비특보 처리 메모 (2026-05-20 추가):**
- `getPwnStatus` 응답의 `t7` 필드에 텍스트로 들어있음. 별도 endpoint 아님.
- 형식: `(1) 강풍 예비특보\no 시간 : 지역\no ...` → `parse_prelim_warnings()`로 그룹·항목 파싱
- 경기북부 10개 시군 키워드 매칭으로 `north_match` 플래그 부여
- 광역 모드: 카운트만 (`발효 N · 예비 M`), 본문 한 줄 안내
- 내관서 중점 모드: 그룹별 상세 표시, 북부 매칭 항목은 노란 점 강조
- 영향예보(Impact-based)는 별도 endpoint 추측 모두 "API not found" → 공공 API 미제공으로 보류

## UI 구성

### 헤더
- 진한 네이비 + 노란 사이렌 로고 박스
- 토글: 광역 / 내관서 중점
- 시군 변경 버튼 (내관서 모드)
- 📡 기상영상 버튼 (기상청 레이더/위성/낙뢰 iframe 모달)
- 🚨 알람 테스트 / 🔊 음소거 / 🌙 테마 토글
- 시계 (큰 노란 글씨)

### KPI 바 6칸
종합상태 / 발효특보 / 재난문자 / 동두천 기온 / 신천 수위 / 군남댐 저수율

### 광역 모드 그리드 (3x3)
```
시군별 기상 (col 1, 3행 전체)  │  발효 특보  │  재난문자
                              │  산불 위험  │  하천 수위
                              │  시간대별 예보 (col 2-3 row 3)
```

### 내관서 중점 모드 (3x3 + 4행 가로 전체)
- 시군 선택 모달 (10개 시군)
- 1행: 현재 기상 / 인근 수위 (여러 하천) / 미세먼지
- 2행: 12시간 예보 / 산불 / 발효 특보
- 3행: 재난문자 / 광역 특보
- 4행: 24시간 시간대별 상세 표 (가로 전체)

### 모달 (6종)
1. 시군 카드 클릭 → 시군 상세 (초단기실황, 누적강수)
2. 하천 클릭 → 24시간 차트 + CCTV(또는 댐 자료 링크)
3. 미세먼지 패널 → 시군별 비교 차트
4. 산불 패널 → 권역별 + 발생 내역 + 4단계 설명
5. 재난문자 항목 → 메시지 전문
6. 발효 특보 패널 → 통보문 + 기상정보 이력
